# DocFlow — базовый сайт хранения документов

## Что уже умеет
- регистрация и вход пользователей;
- загрузка нескольких файлов за раз;
- хранение файлов на сервере и записей о них в SQLite;
- скачивание и удаление собственных файлов;
- просмотр PDF, изображений и текстовых файлов в браузере (зависит от браузера);
- адаптивный интерфейс для телефона, планшета и компьютера;
- изоляция документов: пользователь видит только свои документы.

Поддерживаемые форматы загрузки: PDF, DOC/DOCX, ODT, RTF, TXT, XLS/XLSX, ODS, CSV, PPT/PPTX, PNG, JPG/JPEG, WEBP.  
Для Office-документов предпросмотр в самом сайте пока не встроен: файл можно скачать и открыть в соответствующей программе. Чтобы редактировать Word/Excel/PowerPoint прямо в браузере, потребуется интеграция с ONLYOFFICE Docs или Collabora Online.

## Запуск в Windows
1. Установите Python 3.11 или новее.
2. Распакуйте папку проекта.
3. Откройте PowerShell в папке `DocFlow_Project`.
4. Создайте окружение:
   ```powershell
   py -m venv .venv
   ```
5. Активируйте его:
   ```powershell
   Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
   .\.venv\Scripts\Activate.ps1
   ```
6. Установите зависимости:
   ```powershell
   python -m pip install -r requirements.txt
   ```
7. Для тестового запуска:
   ```powershell
   python app.py
   ```
8. Откройте `http://127.0.0.1:5000` в браузере.
9. Нажмите «Создать аккаунт», зарегистрируйтесь и загрузите документ.

## Как открыть с телефона и другого компьютера
Сейчас это локальная тестовая версия: `127.0.0.1` доступен только на том компьютере, где запущен сайт. Чтобы пользоваться из любого места, разместите приложение на сервере с постоянным диском и HTTPS. Все устройства будут заходить по одному домену, а документы будут храниться на сервере.

Для доступа другим людям не публикуйте отладочный сервер Flask. Используйте production WSGI-сервер, HTTPS, уникальный `SECRET_KEY`, резервное копирование `data/`, ограничения размера/типа файлов и обновления безопасности.

## Важные ограничения и следующий этап
- Документы личные для каждого аккаунта. Общие папки, приглашения и совместное редактирование пока не реализованы.
- Несколько пользователей могут входить и работать одновременно после публикации на сервере; для надёжной эксплуатации рекомендуется PostgreSQL вместо SQLite и объектное хранилище или постоянный диск.
- Сайт не конвертирует документы и не гарантирует, что любой файл можно просмотреть встроенно. Он сохраняет исходный файл, а поддерживаемые браузером типы показывает в предпросмотре.
- Перед реальным использованием добавьте CSRF-защиту, проверку MIME/содержимого файлов, антивирусную проверку, журнал действий, лимиты квоты и автоматические резервные копии.
